\# OVARY-X — Project Definition



\## Project Title



A Personalized Digital Twin for Predicting Short-Term Metabolic Instability in Women with PCOS



\## Problem Statement



OVARY-X explores how historical health information and changing wearable measurements can be combined to estimate a person's evolving metabolic-risk state.



\## Objective



Build a research prototype that fuses historical EHR data with dynamic time-series data, updates a personalized virtual patient state, and predicts a predefined adverse event within a two-hour horizon.



\## Core Pipeline



Historical EHR + Dynamic Wearable Data → Data Fusion → Personal Baseline → Physiological State Estimation → Digital Twin → Two-Hour Risk Prediction → Explanation and Confidence → Doctor Dashboard → Counterfactual Simulation



\## Scope



The prototype will use synthetic, anonymized, or properly licensed open data. It is not intended for clinical diagnosis or treatment.
